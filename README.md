# 暖心家事｜AI 日常事务与家庭协作助手

一个可操作的 Web 原型，演示王阿姨（独居、会用微信语音和大字体智能手机）在安排“下周二社区医院复诊”时，使用 AI 整理、修正内容，并选择是否向女儿小林发出单次陪同请求。小林每周可参与 1–2 次线下协助、但无法持续在线；因此未回应、拒绝和老人撤回均有明确结果。

## 启动

```bash
docker compose up --build
```

打开 http://localhost:8080 。主要演示尺寸：390 × 844 px 手机竖屏（页面也适配桌面）。无需账号、密钥、后端或网络。

## 演示案例

1. 王阿姨：首页 → 开始语音输入 → `下一步` → 在确认页选择 `修改内容`，把事项改为“复诊” → 确认。
2. 选择 `请小林陪我去` → 阅读单次分享范围 → `同意并发送`。
3. 顶部切换到小林 → `我可以陪同` → 自动回到王阿姨的结果页。
4. 重启页面恢复初始状态。替代路径：语音页点 `重新说一遍` 显示“取药”识别错误并手动修正；等待回应时在“我的事务”点撤回；家属端点“这次不方便”显示老人可继续的方案。

## 交付内容

- `PRODUCT.md`：需求依据、范围、信息架构、AI 规则、指标和走查记录。
- `prototype-screens/`：P01–P12（含成功、拒绝、取消等状态）对应的静态原型画面（PNG）。
- `index.html`、`app.js`、`styles.css`：完整可编辑原型源码。
- `Dockerfile`、`docker-compose.yml`：Docker 前端演示。

## 页面和状态清单

见 `PRODUCT.md` 的 P01–P11。所有导航按钮与流程内操作均有可访问画面；原型中出现的数据与状态为预设模拟，不调用真实 AI、消息或医疗服务。
